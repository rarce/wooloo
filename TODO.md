## Terminal performance

Measure every change with `scripts/terminal-bench.sh` and `scripts/terminal-e2e.sh` (`WOOLOO_E2E_LOAD=N` to measure under load); see `docs/perf/README.md`. wooloo draws every frame Herdr sends (about 43 fps). On a 113×48 grid, arrival to draw takes about 0.8–1.5 ms at p50 and a keystroke reaches the draw in about 0.8 ms; the display then adds an estimated 12–15 ms at 120 Hz. Kitty images cost wooloo little. A tab switch draws in 7–13 ms, a two-pane split streams without dropped frames, and the stream thread no longer stalls under machine load. What remains is mostly Herdr's side and the display refresh.

- [ ] Multiple cursors: display columns assume a wide character is exactly two cells, but the editor draws CJK and emoji with a fallback font whose advance is not a whole number of cells (with the 13 pt system monospaced font, about 1.6 for 日 and 2.4 for 👍), and places tab stops in points. - [ ] Multiple cursors: a selection added as a shorter part on a short line becomes the base for the next ⌥⌘↓, so the following lines get the shorter width instead of the original one. Keep the original width with the goal column.
