## Editor

- **Line wrapping.** View > Wrap Lines (also "Toggle Line Wrapping" in the command palette) wraps long lines in document editors. The row at the top stays in place when the window, a sidebar or Markdown's split view changes width, when wrapping is turned on or off, and when the font or line height changes. A 2 MB single-line file now wraps in about 0.1 s.
- **Multiple cursors.** ⌃⌘G adds the previous occurrence (⌘K ⌃⌘G skips to it), since macOS takes ⌃⌘D for Look Up. Cursors added with ⌥⌘↑/↓ line up with what is drawn, including after CJK, emoji and tabs. Each match stepped to from the find bar is its own ⌘U step.
- Tabs are drawn every 4 spaces, the editor's tab width.
- The scroll position of each document is kept when you switch tabs or relaunch, wrapped or not.

## Terminal

- Scrolling output decodes faster: cells are stored row by row, so a frame copies only the rows it changes instead of the whole surface.
- Switching tabs draws the new tab sooner and updates the window once instead of twice, and a key's echo is drawn as soon as it arrives.

## Files, Git and SSH

- SSH loads are much faster: wooloo now notices a finished command at once instead of up to about 60 ms later. A large repository's refresh over SSH dropped from about 200 ms to about 110 ms, and opening a change from about 500 ms to about 80 ms.
- SSH batches run at most twice the remote's processor count at once, which halves the peak memory a refresh uses on a one- or two-core remote.
- Large folders outside Git over SSH no longer fail past the output limit: the walk stops at the file limit, counts only files against it, and the explorer says when a folder has more. Linked folders are described well past the first 5,000 links.
- A command that ignores SIGTERM is killed after its timeout instead of waiting forever.
