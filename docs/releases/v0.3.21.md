## Editor

- **Inline Git Blame** shows the author, date, and commit subject for the active line in local and SSH Spaces. Hover for the full commit SHA and date, or toggle the annotation from Document Actions. [Inline Git blame](https://github.com/rarce/wooloo/pull/192)
- **Home** and **End** move to the start and end of the physical line. **⌘←** and **⌘→** still navigate wrapped rows. The caret stays visible beside the line numbers, and selections have clearer contrast in all bundled themes. [Editor navigation and contrast](https://github.com/rarce/wooloo/pull/193)

## Changes and GitHub

- **Changes** shows a changed-file count on the tab and added and removed line counts on file rows. In a Space rooted in a Git subdirectory, the paths and counts are relative to the Space, including for renames. Diff, stage, unstage, and discard target the selected filename even when it contains brackets. [Changes counts](https://github.com/rarce/wooloo/pull/190) · [Git subdirectory fixes](https://github.com/rarce/wooloo/pull/194)
- Issue and pull request descriptions render Markdown in the GitHub sidebar. Images load on request and show their source host. History, Issues, and Pull Requests display relative dates consistently. [GitHub Markdown](https://github.com/rarce/wooloo/pull/189) · [Sidebar layout](https://github.com/rarce/wooloo/pull/190)

## Terminals and quotas

- Double-click a terminal tab to rename it, or double-click the empty space to its right to create a tab. Expand or collapse quota providers individually, and filter quotas to agents in the selected Space. [Terminal tabs and quotas](https://github.com/rarce/wooloo/pull/190)
