## Markdown preview

- Documents with many tables open, resize and redraw faster in both Theme and Document styles. Long documents prepare their blocks as they come into view, and table borders require less layout work.
- Changing the theme correctly refreshes heading and table colors.

## Jupyter notebook preview

- **Find stays responsive in large saved outputs.** Highlighting thousands of matches in an HTML dataframe no longer repeatedly walks the entire table for every match. Local Release measurements of 5,001 matches fell from about 15 seconds to 21–64 ms for the WebKit call through a viewport capture; this excludes the native Find-bar update and regex scan.
- **Large source cells and saved text outputs prepare faster.** The preview reads only the text prefix it will display. The 500,000-character limit still counts complete Unicode graphemes, and the full original notebook remains available in Source view. Parsing a 3.2 MB source cell measured 416 → 45 ms locally.

## Performance checks

- Repeatable Release benchmarks now cover Markdown tables and notebook opening, Find, resizing, scrolling and saved images, with before/after measurements and visual references. Notebook captures use a wider regression threshold to account for measured WebKit timing variation; parser and JavaScript checks retain the tighter threshold.
- The measurements above are medians from seven notebook repetitions on a Mac16,5 running macOS 26.6.2. Results depend on the document and machine; see the [performance notes](https://github.com/rarce/wooloo/blob/main/docs/perf/README.md) for workloads and limits.
