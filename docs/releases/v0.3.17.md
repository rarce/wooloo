## Connections

- **Manage Herdr connections per window.** A single **Connections…** panel, available from the sidebar, the actions menu and the command palette, replaces the separate local-session picker and remote-host manager. Each row shows server or access status and whether the connection is open in this window, and local sessions include stopped ones. **Remove from This Window** closes a connection without stopping its server or affecting other windows. Each window restores its own connections. The panel also adds connections and manages Herdr's saved SSH profiles. Unsaved editor text from a connection that was closed or removed can be recovered with **Preserved drafts → Save a Copy…**. ([#141](https://github.com/rarce/wooloo/pull/141))

## Tabs and windows

- **Keep tab drags from moving the window.** Dragging a tab in windowed mode no longer moves the window too. Only empty areas of the header move the window. ([#142](https://github.com/rarce/wooloo/pull/142))

## Documents

- **Faster notebooks and Markdown tables.** Large notebooks open faster, and cell edits and jumps to distant Find results do less rendering work. Large Markdown tables open about 25–30% faster. ([#140](https://github.com/rarce/wooloo/pull/140))

## Diagnostics

- **More context in hang reports.** When wooloo stops responding, the local hang report now records the UI events leading into the freeze, up to three repeated thread samples and a memory timeline. Reports stay on this Mac and exclude document text, keystrokes and notification bodies. ([#143](https://github.com/rarce/wooloo/pull/143))

## Included runtime

The app includes [Herdr 0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5). Requires macOS 14 or later.
