## Editor

- **Open files follow the disk.** A tab without unsaved edits reloads when its file changes on disk, preview tabs and Markdown/notebook previews included, keeping the cursor and scroll position; the reload can be undone. A tab with edits keeps them and shows a banner with **Reload** and **Keep Mine**. Saving over a newer file asks first (**Overwrite / Reload / Cancel**) instead of failing. A file deleted on disk keeps its tab, struck through, and Save creates it again. Local Spaces check on file events, SSH Spaces every 3 s while the app is active, and both before every save.

## Terminal

- Clicking a pane always focuses it. Clicking back into the pane focused before did nothing.
- Split dividers show a resize cursor when hovered and while dragged.
