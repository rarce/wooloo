## Markdown

- **Expand Mermaid diagrams.** Open a diagram in a larger viewer, zoom with the trackpad or toolbar, and pan by dragging or scrolling. Fit, actual size and keyboard controls make wide diagrams easier to read. Closing the viewer preserves the document's scroll position. ([#131](https://github.com/rarce/wooloo/pull/131))
- **Keep preview scroll state local.** Restoring a saved position against edited text no longer changes the saved anchor for a preview already on screen. This corrects a confirmed scroll-state defect; the reported freeze while scrolling Markdown tables has not been reproduced deterministically. ([#133](https://github.com/rarce/wooloo/pull/133))

## Tabs and Spaces

- **Drag tabs from the titlebar.** Dragging a terminal, document or Search tab starts the tab drag instead of moving the window. Empty header areas remain available for moving the window. ([#132](https://github.com/rarce/wooloo/pull/132))
- **Show the new-Space hint only during terminal tab drags.** The sidebar drop area appears for terminal tabs from the corresponding host and disappears when the mouse is released, including outside a valid destination. Document and Search tab drags do not show it. ([#130](https://github.com/rarce/wooloo/pull/130))

## Development

- Development builds can override `WOOLOO_APP_BUNDLE_IDENTIFIER` to give concurrent worktrees separate macOS identities and preferences. ([#133](https://github.com/rarce/wooloo/pull/133))
