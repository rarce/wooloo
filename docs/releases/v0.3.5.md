## Mobile access to remote sessions

- **Connect directly to a reachable SSH server.** Open Settings → Remote Access while connected to a remote host to generate a QR for that server and session. Set the hostname and SSH port that your phone can reach. A publicly reachable SSH service does not need a Cloudflare tunnel; local Mac access keeps the existing Cloudflare setup.
- **Authorize your phone on the selected machine.** Copy the device's public SSH key from herdroid and paste it into wooloo. Before installing it, wooloo shows the key fingerprint, destination account, `authorized_keys` path and the SSH access being granted. For a remote session, the public key is installed on that server through the saved SSH connection. The private key stays on the phone. Authorization applies to the account across its sessions.
- **Preserve existing key restrictions.** Reauthorizing a key keeps its existing options and avoids adding an unrestricted duplicate, including entries with Windows line endings or non-UTF-8 options. If the existing-key scan fails, authorization stops without appending a key.

The phone must be able to reach the advertised SSH hostname and port independently of the Mac's SSH aliases, jump hosts or VPN. A domain name alone does not make SSH reachable. The QR supplies connection details; key authorization is a separate, explicit action.

## Editor and remote files

- **Compare unsaved edits with disk.** When an open file changes externally, choose Compare to inspect read-only disk and editor snapshots in a unified or split diff before choosing Reload or Keep Mine. Refresh captures both versions again. Local and SSH files are supported.
- **Keep large remote folders usable.** Explorer and Go to File retain a valid partial listing when SSH folder output reaches its 32 MB limit, rather than failing the entire listing. Truncated results remain marked as partial.

## Terminal

- **Restore scrolling and appearance after switching clients.** Returning to wooloo after attaching Ghostty to the same Herdr session restores terminal-history scrolling, colors and focus state. Herdr's scrollbar now appears as continuous blocks.

## Included runtime

The app now includes [Herdr 0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5), matching the current upstream release. Existing external Herdr installations can still be used. Requires macOS 14 or later.
