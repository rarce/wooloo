## Files and navigation

- Press **⇧⌘T** or type `#` in **Go to File** to find a symbol across a local or SSH Space. Select a result to jump to its definition. Search covers Swift, JavaScript, TypeScript, JSX, TSX, Python and Markdown headings. [Space-wide symbol search](https://github.com/rarce/wooloo/pull/172)
- Open a local binary file in its default macOS app or reveal it in Finder. Wooloo also recognizes large binary files on SSH hosts and identifies them as remote files. [Binary file handling](https://github.com/rarce/wooloo/pull/171)
- Return to a recently visited Space to see its Files and Changes immediately while wooloo checks for updates in the background. If a refresh fails, the last listing stays visible. [Explorer caching](https://github.com/rarce/wooloo/pull/174)
- Scrolling through tables in the Markdown preview now does less layout work per frame. [Markdown scrolling](https://github.com/rarce/wooloo/pull/173)

## Sidebar and ports

- Collapse a host to see its notification total and a single activity indicator. Expand it to see activity per Space. Blocked and error states take priority. Host connection actions are available in each Space’s context menu. [Sidebar changes](https://github.com/rarce/wooloo/pull/175)
- Stale port badges clear when scanning pauses, fails or the host disconnects. Browser shortcuts filter out known ADB, PostgreSQL and Cloud SQL Proxy listeners. Remote TCP ports remain available through **TCP Port Forwarding**. [Port discovery](https://github.com/rarce/wooloo/pull/175)
