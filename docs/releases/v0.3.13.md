## Editor

- **One document toolbar.** The filename stays in its tab instead of repeating in the header and breadcrumbs. Each panel keeps its own navigation and document controls, with compact menus for narrow panels. File location and actions are available in the document menu. ([#121](https://github.com/rarce/wooloo/pull/121))
- **Clearer file tabs and Find focus.** Homonymous files remain distinguishable when their diffs are open too. Closing Find returns keyboard focus to the document. Existing controls for Markdown, notebooks, diffs, PDFs and images are preserved. ([#121](https://github.com/rarce/wooloo/pull/121))
- **Previews remember their scroll position.** Switching tabs and back restores Markdown and notebook previews to where they were during the current session. Markdown restores the top block; notebooks restore the top cell and its offset, including while outputs above it load. This position is not saved across app launches. ([#116](https://github.com/rarce/wooloo/pull/116))

## GitHub

- **Open issue and pull request totals.** The GitHub sidebar shows repository-wide counts, including while collapsed, rather than the size of the displayed lists, which are limited to 50 items. Refreshing collapsed counts also invalidates cached lists so expansion fetches current entries. ([#119](https://github.com/rarce/wooloo/pull/119))

## Diagnostics

- **Local hang reports.** If the app stops responding for a few seconds, it records a sample of its own threads in `~/Library/Logs/wooloo/Hangs`, keeping the last 20 reports. Reports stay on your Mac; nothing is uploaded automatically. ([#117](https://github.com/rarce/wooloo/pull/117))
- **Downloadable debug symbols.** Releases now include `wooloo-0.3.13.dSYM.zip`, matching the app binary, to help symbolicate crash and hang reports. ([#117](https://github.com/rarce/wooloo/pull/117))

## Maintenance

- Documentation-only pull requests skip the macOS build and test job; changes to app code, build configuration and releases still require CI. ([#120](https://github.com/rarce/wooloo/pull/120))
- Updated the website's feature descriptions for the previous release. ([#115](https://github.com/rarce/wooloo/pull/115))
