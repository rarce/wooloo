## Tabs and Spaces

- **Tabs in the window titlebar.** Terminal, document and Search tabs share a compact row beside the native window controls, leaving more room for content. New-terminal and new-file controls stay visible when tabs overflow, and an all-tabs menu makes hidden tabs reachable. Selecting Search also focuses its search field when it is already open in a split. ([#127](https://github.com/rarce/wooloo/pull/127))
- **Drag Spaces and terminal tabs.** Reorder Spaces in the sidebar, or move a single-pane terminal tab to another Space or the new-Space drop area within the same destination. Multi-pane and zoomed tabs, and drops across sessions, machines or windows, are not supported. ([#125](https://github.com/rarce/wooloo/pull/125))

## SSH Preferences

- **Edit the selected SSH account's Herdr settings.** Preferences now separates this Mac's Wooloo settings from the selected SSH account's Herdr configuration, including pane gaps and Advanced TOML. Headers identify the account, session and configuration file; unsaved edits require confirmation before changing scope or closing Preferences. ([#126](https://github.com/rarce/wooloo/pull/126))
- **Safer saves and clearer reload results.** Remote saves preserve configuration symlinks and permissions, check for external edits, and distinguish saving from applying the configuration. A failed reload can be retried without rewriting the file. The displayed file is discovered over SSH; sessions started with different environment overrides may use another configuration path. ([#126](https://github.com/rarce/wooloo/pull/126))
- **Local settings reach every window.** Saving this Mac's theme and shortcuts updates other Wooloo windows too. ([#126](https://github.com/rarce/wooloo/pull/126))

## Files and Search

- **File actions follow the selected Space.** Project search, Go to File and new-file actions update when switching Spaces even with the Files sidebar hidden. Results and replacement confirmations from an earlier Space or query are invalidated, while open documents and pending saves retain their original file locations. ([#123](https://github.com/rarce/wooloo/pull/123))
- **Reliable symbol navigation.** Go to File can navigate symbols in documents outside the current project root and documents kept open after a root change, while rejecting selections made stale by a document, Space or destination change. ([#123](https://github.com/rarce/wooloo/pull/123))
