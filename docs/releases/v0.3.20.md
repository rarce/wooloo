## Agent quotas

- See Antigravity usage and reset times by model group in **QUOTAS**. This works locally and over SSH on machines with Antigravity CLI 1.1.11 or later. If you already enabled quotas, confirm the updated consent once per machine. [Antigravity quotas](https://github.com/rarce/wooloo/pull/187)

## Search, files and GitHub

- **⌘F** and **⇧⌘F** place the cursor in the search field when you open or return to Find or Project Search. Use **⌘B** to toggle the left sidebar and **⇧⌘B** to toggle Files and Changes. [Search and shortcuts](https://github.com/rarce/wooloo/pull/178)
- Open an issue or pull request in the GitHub panel with one click to see its description, state and age. **⌘-click** opens it in your browser. [GitHub navigation](https://github.com/rarce/wooloo/pull/178)
- In SSH Spaces outside Git, expand recognized folder symlinks directly in the explorer. **Go to File** skips those folder links and still lists symlinks to files. [SSH file listing](https://github.com/rarce/wooloo/pull/182)

## Terminals

- The terminal cursor appears at the correct cell without a second blinking caret in the corner. [Cursor fix](https://github.com/rarce/wooloo/pull/180)
- When two windows in the same wooloo instance show the same herdr-core terminal, resizing the background window leaves the focused window in charge of the terminal size. If focus returns during the switch to watching, the window keeps its active stream and can still accept input. [Core window sizing](https://github.com/rarce/wooloo/pull/183)
