## Tabs

- **Reorder terminal and document tabs again.** Drag tabs left or right within their group and the new order is retained. This fixes the drag-and-drop regression reported in [#67](https://github.com/rarce/wooloo/issues/67).

## Performance

- **Refresh large local workspaces faster.** Local file and Git refreshes avoid redundant work, reducing the time needed to update the explorer in large repositories.
- **Make performance regressions easier to catch.** The performance suite now records comparable run metadata and covers editor, search and resource usage alongside the terminal benchmarks.

## Included runtime

The app includes [Herdr 0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5). Requires macOS 14 or later.
