## Terminal and files

- **Open file paths with Command-click.** Paths printed by compilers, tests and other terminal programs open in the editor at their line and column, locally and over SSH. Relative paths use the pane’s current directory, including after a `cd` without a new snapshot. Hidden files and wrapped paths are recognized; hover checks preserve the underline while refreshing and the click reuses the resolved path. ([#89](https://github.com/rarce/wooloo/pull/89))
- **A Space’s file root follows its first tab’s root pane**, matching Herdr instead of choosing another pane’s directory. ([#88](https://github.com/rarce/wooloo/pull/88))

## Editor

- **Code uses the terminal’s font family** across the editor, diffs, search and commit messages, while retaining the configured code size. Editor text and line numbers inherit native macOS smoothing, with baselines aligned to device pixels. ([#90](https://github.com/rarce/wooloo/pull/90))
