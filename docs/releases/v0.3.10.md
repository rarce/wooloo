## Spaces across hosts

- **Open Spaces directly from groups for each host and session.** Local and SSH destinations stay visible together, with connection status, attention badges and a New Space action for each group. Switching destinations restores their selected Space, terminal tab, pane and editor context. ([#95](https://github.com/rarce/wooloo/pull/95))
- **Return to the previous context** from the command palette or with the configurable app shortcut, `prefix+backspace` by default. The status bar identifies the current host and session even when the sidebar is hidden.
- **Keep work attached to its destination.** Notifications, pending actions and editor sessions stay scoped to their host. Multiple windows share background host metadata while keeping their own selection. Disconnected hosts retain their cached Space list.

## Editor

- **See Git changes beside the scrollbar.** A narrow rail shows additions, modifications, staged changes and deletions across the document, including unsaved edits. Click a marker to center the change without moving the cursor or selection. ([#93](https://github.com/rarce/wooloo/pull/93))
- **Avoid unnecessary layout when opening long wrapped lines.** Text shaping waits until the editor has a usable width instead of first laying out an invisible unwrapped row. ([#92](https://github.com/rarce/wooloo/pull/92))
