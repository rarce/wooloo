## Git synchronization

- **Sync incoming and outgoing commits in one action.** When a branch has both, the Git bar shows `Sync ↓N ↑M`, integrates remote commits first, and pushes only after integration succeeds. Existing merge/rebase settings are respected; without a policy, choose Merge or Rebase for that operation. Conflicts stop publication, and a failed push preserves the completed pull. ([#100](https://github.com/rarce/wooloo/pull/100))
- **Keep different Git destinations separate.** Automatic Sync is offered only for a verified shared fetch/push destination, including Git URL rewrite rules. Repositories with different or ambiguous destinations retain separate Pull and Push actions.

## Explorer and GitHub

- **Browse History and Branches within Explorer.** Compact tabs and an overflow menu keep destinations accessible in narrow sidebars. The main tab strip now groups contiguous tabs with file-type icons and close controls on active or hovered tabs. ([#99](https://github.com/rarce/wooloo/pull/99))
- **Browse GitHub issues and pull requests from the sidebar.** Read-only lists use the Space host's existing `gh` authentication, support manual refresh, and let you open or copy links. SSH hosts require `gh` installed and authenticated there.

## Editor

- **Improve reflow performance for long wrapped lines.** Text layout avoids unnecessary fragment allocations during opening, insertion and resizing. ([#101](https://github.com/rarce/wooloo/pull/101))
- **Make rectangular selection more consistent in mixed-direction text.** Option-drag follows the screen rectangle through RTL text and soft wraps while preserving whole graphemes and visual caret edges through undo/redo.
- **Preserve the viewport during edits in hidden wrapped rows.** Grouped replacements and undo/redo retain a stable viewport anchor and publish final selections together.

## Host statistics

- **See GPU utilization in HOST.** Expanded stats show each available GPU; collapsed stats show the busiest one. macOS readings work locally and over SSH; Linux SSH hosts support NVIDIA and AMD counters when available. ([#98](https://github.com/rarce/wooloo/pull/98))
