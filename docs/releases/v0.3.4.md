## Terminal panes and keyboard

- **Keep agent shortcuts available.** The default wooloo prefix is now Control+Command+B, leaving Control+B available to terminal programs such as Claude Code. Explicit Herdr prefixes still take priority. Press a configured prefix without Command twice to send it to the terminal; repeating a Command prefix cancels it. Existing `ctrl+b` configurations can be changed to `cmd+ctrl+b` in Settings → Shortcuts.

- **Rearrange split terminals.** Use the Move Terminal context menu or the hover handle to place a running terminal beside another pane. Drag the handle onto the tab bar, or choose Move to Own Tab, to give it its own tab while keeping the terminal and process running.
- **Modified keys reach Herdr intact.** Control, Option and Shift combinations are preserved for special keys and modified characters in terminal panes and popups. Option+Left and Ctrl+Left no longer become plain Left, and Ctrl+Shift+A retains Shift for programs using enhanced keyboard input. Native Command shortcuts and text composition keep their existing behavior.
- **Recover from stalled connections.** Connections that stop responding during startup or sending, or leave an incomplete frame, now time out and reconnect. Endpoints advertising health checks also recover when they become completely silent. Reconnection clears stale state and restores the selected pane and latest viewport size.

## Spaces and remote hosts

- **Confirm closing a Space’s last terminal.** Closing the last tab or pane asks whether to Close Space or Keep Space, including Command+W, middle-click and terminal/agent menus. Keep Space preserves the existing terminal and running agent; Close Space closes that workspace.

- **See pending commits beside each Space.** The sidebar shows `↑N` for commits ahead of upstream and `↓N` for commits behind, using Herdr's existing Git information. Zero counts stay hidden.
- **Manage saved SSH hosts.** Choose Manage Remote Hosts… from the sidebar's session/host picker to add, rename, enable, disable or remove a host. Herdr prepares and saves the remote profile; SSH aliases, keys and ports follow OpenSSH configuration. Connect in Terminal first if SSH needs a password or host-key confirmation.
- **Switch the whole session between hosts.** Selecting a host switches Spaces, terminal tabs and panes, agents, files, Git operations, host information and quotas to its saved remote session. Commands and terminal input go to that server. Returning to Local restores the local session; open documents and unsaved edits stay separate by machine and Space. Failed remote connections stay remote instead of falling back to local data.

## File syntax

- **Colors for configuration files.** `.conf`, `.cfg`, `.ini` and `.properties` files now highlight sections, keys, values, numbers, booleans and comments in both the editor and diffs. Common Git and EditorConfig configuration names are recognized too.
- **Choose a syntax manually.** Click `Auto: <language>` in the document header to search the available syntaxes, select Plain Text or return to automatic detection. The choice survives session restoration and saving a draft. Syntax changes preserve selection and undo history, and switching to HTML, JSX or TSX keeps closing-tag insertion and newline indentation working.
- **Save file associations.** Associate a filename or workspace-relative pattern with a syntax across workspaces. More specific patterns take priority, and manual document choices override automatic associations. Rules can be replaced or removed from File Associations… in the selector.

The bundled runtime remains Herdr 0.9.3. INI/Properties highlighting is line-oriented; specialized Nginx and SSH configuration grammars are not included.
