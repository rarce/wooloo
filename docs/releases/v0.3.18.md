## herdr-core preview

- Connect to the server behind the official Herdr app from wooloo, locally or over SSH. To try it on this Mac, install herdr-core and enable **Settings → Appearance → herdr-core (preview)**. The Herdr TUI remains the default. [Setup and supported features](https://github.com/rarce/wooloo/blob/v0.3.18/docs/herdr-core-preview.md)
- Open terminals from the official app alongside wooloo’s Spaces, tabs and splits. In a core terminal, use **⌘F** to search scrollback, scroll to a match and see it highlighted. Terminal programs can receive mouse input, display inline PNGs and handle Ctrl+C in Kitty keyboard mode. [Terminal support](https://github.com/rarce/wooloo/pull/159) · [Keyboard fix](https://github.com/rarce/wooloo/pull/162)

## Spaces and windows

- Open a development server from its Space’s **HTTP** badge in the sidebar. For an SSH Space, wooloo forwards the port to this Mac and opens it in your browser. [Listening ports](https://github.com/rarce/wooloo/pull/146)
- New windows inherit the front window’s connection. Quitting after cancelling a tab drag no longer hangs while macOS waits for the drag to finish. [New windows](https://github.com/rarce/wooloo/pull/161) · [Quit fix](https://github.com/rarce/wooloo/pull/167)

## Included runtime

Requires macOS 14 or later. The app includes [Herdr 0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5). The optional core preview was tested with herdr-core 0.1.21.
