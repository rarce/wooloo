## Editor

- **Navigate code with an Outline and breadcrumbs.** Markdown, Swift, JavaScript/TypeScript (including JSX/TSX) and Python files get a collapsible Outline and navigable breadcrumbs, built on the existing Tree-sitter tree; no language server is needed. ([#94](https://github.com/rarce/wooloo/pull/94))
- **Richer status bar.** The footer shows selection counts, go-to-line, language selection, encoding and line endings, wrapping and persistent indentation controls, with a compact layout for split panes.
- **Better Markdown highlighting.** Headings, links, emphasis, inline code and fenced code are colored correctly, including combined bold and italic.
- **Go to Symbol in File (⇧⌘O, or `@` in Go to File).** Lists the symbols of the focused file with their kind, containers and line; pressing ⇧⌘O again selects the next symbol. ([#112](https://github.com/rarce/wooloo/pull/112))
- Fixed a crash when deleting the last character of highlighted source without a trailing newline.

## Notebooks

- **Edit cells in the preview.** Edit a cell's source, change its type, move, insert or delete cells. Edits rewrite only the changed JSON value, so metadata, outputs and the file's formatting are kept, and undo works in Preview and Split modes. ([#104](https://github.com/rarce/wooloo/pull/104))
- **Semantic notebook diffs.** Diffs of `.ipynb` files show changed cells with what changed (source, outputs, execution count, metadata, attachments, type); a Cells/JSON toggle keeps the raw diff available.
- **Large notebooks stay responsive.** Cell edits are computed off the main thread and undo uses much less memory ([#107](https://github.com/rarce/wooloo/pull/107)). The preview keeps only the cells near the viewport: a 4,096-cell notebook first renders in 2 s instead of 6.3 s, and scrolls and resizes far faster ([#108](https://github.com/rarce/wooloo/pull/108)).
- **Edit truncated cells.** A cell the preview truncated (over 500,000 characters) opens with its whole source. ([#113](https://github.com/rarce/wooloo/pull/113))

## SSH Spaces

- **Open files follow the disk.** Tabs of files on SSH machines reload when clean, or show the Reload / Keep Mine banner when edited, while the app is active, even for Spaces not shown in the explorer. The poll pauses in hidden windows and backs off on unreachable machines. ([#110](https://github.com/rarce/wooloo/pull/110), [#113](https://github.com/rarce/wooloo/pull/113))
- **No more stalls on hung mounts.** Checks on symbolic links in the remote walk are time-bounded, linked folders the walk skipped open as folders, and a walk cut at the file limit still lists skipped folders. ([#111](https://github.com/rarce/wooloo/pull/111))
- **Never another Space's files.** Switching to an SSH Space shows a spinner until its own files arrive, instead of briefly showing the previous Space's tree. ([#109](https://github.com/rarce/wooloo/pull/109))

## Remote Access

- **Every account is checked.** The SSH safety check now covers all local accounts allowed to use SSH (including `com.apple.access_ssh` members), and sshd is rechecked every 5 minutes while the tunnel runs; the tunnel stops if sshd becomes unsafe. ([#113](https://github.com/rarce/wooloo/pull/113))
