## Editor

- **Open long documents and Markdown tables faster.** Documents with very long wrapped lines open much faster (a 2 MB single-line fixture went from 1.6 s to about 0.1 s), and Markdown previews with large tables render roughly 1.7× faster. ([#78](https://github.com/rarce/wooloo/pull/78))
- **JSON keys and `true`, `false` and `null` are colored again** in the editor and in diffs. ([#79](https://github.com/rarce/wooloo/pull/79))
- **Saves no longer overwrite changes made while saving.** If a file is edited, deleted or retargeted while wooloo prepares a local or SSH save, the save is rejected instead of replacing it. ([#80](https://github.com/rarce/wooloo/pull/80))

## Files

- **Switching Spaces no longer leaves the explorer spinning** behind a slow or blocked folder listing from the previous Space. ([#81](https://github.com/rarce/wooloo/pull/81))

## Reliability

- Remote Access output handling and the remote Herdr bridge were hardened against concurrent shutdown and late output, as part of an ongoing Swift concurrency migration. ([#82](https://github.com/rarce/wooloo/pull/82), [#83](https://github.com/rarce/wooloo/pull/83))

## Included runtime

The app includes [Herdr 0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5). Requires macOS 14 or later.
