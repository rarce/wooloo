## Terminal input

- **Type accents and keyboard-layout symbols with Option.** The terminal now passes Option character input through macOS text handling, including dead keys, while preserving Control chords, Option navigation and configured Herdr shortcuts. ([#76](https://github.com/rarce/wooloo/pull/76))

## Appearance

- **Choose whether inactive windows dim.** Turn off **Dim inactive windows** in Preferences → Appearance → Window focus to keep inactive windows at their normal brightness. The setting applies immediately and persists across launches; dimming remains enabled by default. ([#77](https://github.com/rarce/wooloo/pull/77))

## Included runtime

The app includes [Herdr 0.9.5](https://github.com/herdrdev/herdr/releases/tag/v0.9.5). Requires macOS 14 or later.
