ADE vs IDE: from writing code to shaping software ↗

Keep the whole development loop in view.

Your agents write code. You shape the work through plans, evidence and decisions. wooloo brings the files, previews and Git tools you need into the workspace where your agents run.

  1. Intent
  2. Proposal
  3. Evidence
  4. Review
  5. Integrate

01 / Review the proposal

Start with the intent.

Read the agent’s plan as a rendered Markdown document. Explore Mermaid diagrams and examine the reasoning before steering the next step.

The proposal stays beside the project files, ready to revisit as the work evolves.

02 / Inspect the evidence

Make results part of the review.

Open Jupyter notebooks to inspect saved outputs, tables and charts. Compare the evidence with the intended behavior, in the same workspace.

Edit cells and review notebook diffs. Run the notebook with your own tools when you need fresh results.

03 / Evaluate the change

Follow the diff through to the commit.

Review unified or split Git diffs, including notebook changes cell by cell. Stage the changes you accept and write the commit message in wooloo.

Branches, history and worktrees keep parallel tasks connected to their repository context.

04 / Keep the context

Your repository belongs in the workspace.

Browse the repository’s open issues and pull requests from the current Space. Keep the next task and ongoing work in view while you evaluate the changes.

Select an issue or PR to open its details in your browser. Connect through the GitHub CLI account already configured on the Space’s host.

Know when to step in

See agent activity and unread completions across Spaces. Notifications draw your attention when an agent finishes or needs input; live terminals let you respond.

Keep your own tools

Run the agent CLIs you already use. Browse local or SSH files, search the project, and make direct edits when you need them.

Come back to the session

Herdr, included with wooloo, owns the terminals and processes. Sessions keep running when you close wooloo, while their host and Herdr server remain running.

Your Mac, your data

No telemetry in the app

The wooloo app has no analytics. It talks to Herdr on your Mac, your saved SSH machines, your Git remotes and GitHub for updates. Everything else is opt-in. What the app connects to.

This website is different: it counts visits with Google Analytics.

Quotas, only if you agree

Optionally shows your Claude Code and Codex plan usage. It reads their sign-ins and calls unofficial endpoints that can change, so it stays off until you agree to a dialog that says exactly what it reads. How Quotas works.

Remote access, if you want it

Publishes this Mac's SSH server through a Cloudflare Tunnel. Off by default. wooloo checks whether SSH accepts passwords for any account allowed to log in, asks before publishing if it does, and checks again while the tunnel runs. It never changes your SSH settings. Read this first.

Get started

  1. Download the latest wooloo-<version>.zip from GitHub Releases, unzip it and drag wooloo.app to Applications in Finder.
  2. Open it once. Then go to System Settings → Privacy & Security, click Open Anyway, confirm with Open Anyway again and enter your password or use Touch ID. Or remove the quarantine flag: 
    xattr -dr com.apple.quarantine /Applications/wooloo.app
  3. In the setup window, keep Use included Herdr, then Choose Folder… and pick a project folder. wooloo opens it with a terminal.
  4. In that terminal, start an agent CLI you already have, such as claude or codex. It appears in the Agents list, and the files it changes show up in the explorer and the Changes tree.

Agent CLIs, their accounts and their subscriptions are separate from wooloo: install and sign in to each agent on its own. wooloo is an early preview and not notarized yet, so macOS warns on the first launch. You can also build it from source.

Your agents on your phone

wooloo mobile follows the same Herdr sessions from Android: each agent's state, an alert when one finishes or needs you, and a live terminal to answer it. Scan the QR code that Remote Access shows in wooloo to connect to this Mac, or add any machine running Herdr over SSH. It is in a closed test on Google Play, and you can join it.
