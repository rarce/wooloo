A native macOS home
for your coding agents

wooloo is an open source Mac app for Herdr, the server that runs and organizes coding agent sessions. Live terminals, a file explorer, an editor and Git tools, without leaving an environment built around your agents.

Download for macOS View on GitHub

Free and MIT licensed · macOS 14 or later · Apple silicon and Intel · Herdr included

Everything around the agent, natively

Herdr keeps owning the processes, layout and terminal state, so the same sessions stay available from the Herdr TUI. wooloo renders them natively and sends your input back.

Agents and sessions

  • Spaces, tabs and split panes from Herdr, managed from the sidebar, menus or command palette.
  • Every agent with its Space, summary and status at a glance.
  • Alerts when an agent finishes or needs input, with unread marks.
  • The host's CPU, memory and disk, local or over SSH.

Terminal

  • Live surfaces over Herdr's binary endpoint, drawn with Core Text at Herdr's frame rate.
  • Colors, alternate-screen apps, inline images, mouse reporting and clickable links.
  • Drag split borders to resize; select, copy, paste and drop file paths.
  • Herdr's prefix and direct key bindings, from the same config.toml.

Files and editor

  • An explorer for local and SSH Spaces, with Git status, drag and drop, and undo.
  • Go to File (⌘P), a command palette (⇧⌘P) and project-wide search and replace.
  • Syntax-highlighted editor tabs with change bars and multiple cursors.
  • Markdown with Mermaid, Jupyter notebooks, images and PDFs.

Git

  • A Changes tree with stage checkboxes, a branch bar and a commit editor.
  • Unified or split diffs with syntax colors.
  • History with each commit's files, branches, and worktrees that refuse to drop dirty work.

Your Mac, your data

No telemetry

wooloo has no analytics. It talks to Herdr on your Mac, your saved SSH machines and your Git remotes. Everything else is opt-in.

Remote access, if you want it

Publish this Mac's SSH through a Cloudflare Tunnel to reach your sessions from elsewhere. Off by default; use key-only SSH first.

Open source

MIT licensed and built in the open. Read the code, file issues and send pull requests on GitHub.

Install

  1. Download the latest wooloo-<version>.zip from GitHub Releases, unzip it and move wooloo.app to Applications.
  2. Open it once. Then go to System Settings → Privacy & Security and click Open Anyway, or remove the quarantine flag: 
    xattr -dr com.apple.quarantine /Applications/wooloo.app

wooloo is in early development and not notarized yet, so macOS warns on the first launch. You can also build it from source.
